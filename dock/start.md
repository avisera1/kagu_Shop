1.コンセプト
一言でいうと: ０から始める完全オーダーメイド家具屋を紹介するお店・ブランドサイト
子供向けの家具から、大人向け、法人向けの家具まで
ターゲット: ベテランの富裕層、ファミリー層(金持ち)

| フロントエンド | HTML,CSS,js|
| インフラ | git hub pages| 

3.機能一覧
・クリックでメニュー展開/格納
・質問送信システム
・交通アクセスマップをグーグルマップで表示 

4.UI/UX・画面構成
ホーム：タイトル、キャッチ-、紹介
ヘッター：メニュー・ホーム（店名）・問い合わせボタン
フッター：ポリシー、営業時間、日時、会社概要
メニュー：（カテゴリ、苗、Q＆A、店紹介、サービス）
ダッシュボード (/dashboard): メインの操作画面
詳細画面 (/detail/[id]): 個別データの表示
